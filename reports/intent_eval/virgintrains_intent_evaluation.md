# Intent classification on the golden set

Generated by `python scripts/evaluate_intents.py`. Input to every system: the opening customer message only. Gold: human labels made from the full conversation.

## Setup

- Baselines fitted on `train_retrieval` (13,742 cases), C chosen on `dev_calibration` (2,133 cases); their labels are weak cluster-derived candidate intents, not human labels. Golden was never used for fitting or selection.
- Majority class: `service_status_delay_enquiry`.
- TF-IDF + logistic regression: C = 3.0 (dev macro-F1 by C: 0.1: 0.685, 0.3: 0.719, 1.0: 0.748, 3.0: 0.771, 10.0: 0.767).
- LLM classifier: the agent's `IntentClassifier` on groq, model `openai/gpt-oss-120b`. All cases predicted.
- Label provenance: assistant_draft_confirmed: 150, human: 100.
